Atomes et molécules

Cours de physique-chimie de 5e (mélanges et réactions chimiques), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • La matière est constituée de particules extrêmement petites : les atomes.
  • Chaque sorte d’atome est représentée par un symbole : C (carbone), H (hydrogène), N (azote), O (oxygène), S (soufre), Cl (chlore). Dans les modèles, ils ont des couleurs conventionnelles : C noir, H blanc, N bleu, O rouge, S jaune, Cl vert.
  • Une molécule est un ensemble d’atomes liés entre eux.
  • La formule d’une molécule indique la nature et le nombre de ses atomes ; l’indice s’écrit en bas à droite du symbole : H2O (2 H, 1 O), CO2 (1 C, 2 O), CH4 (1 C, 4 H).
  • Un corps simple est formé d’un seul type d’atome (O2, H2, N2) ; un corps composé de plusieurs types d’atomes (H2O, CO2).

Quiz : teste-toi

1. Le symbole de l’atome d’oxygène est :
  1. Ox
  2. O
  3. Og
  4. X

Réponse : O. O.

2. Dans les modèles, l’atome de carbone est :
  1. rouge
  2. blanc
  3. noir
  4. bleu

Réponse : noir. Noir.

3. La molécule CH₄ contient :
  1. 1 C et 4 H
  2. 4 C et 1 H
  3. 1 C et 1 H
  4. 5 C

Réponse : 1 C et 4 H. L’indice 4 porte sur H.

4. Lequel est un corps composé ?
  1. O₂
  2. N₂
  3. H₂O
  4. H₂

Réponse : H₂O. H₂O contient deux types d’atomes.

5. Une molécule est :
  1. un atome seul
  2. un groupe d’atomes liés
  3. un mélange
  4. un ion

Réponse : un groupe d’atomes liés. Des atomes liés entre eux.

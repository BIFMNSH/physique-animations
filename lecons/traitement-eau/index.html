Traitement de l’eau

Cours de physique-chimie de 4e (eau potable), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • L’eau naturelle (rivière, lagune, puits) n’est pas toujours potable : elle peut contenir des débris, des particules en suspension et des microbes.
  • Dégrillage : une grille arrête les gros débris.
  • Décantation : au repos, les particules lourdes tombent au fond. Filtration : le sable et le gravier retiennent les fines particules. L’eau devient limpide.
  • Désinfection : le chlore (ou l’eau de Javel, l’ozone) détruit les microbes. Une eau limpide n’est pas forcément potable.
  • L’eau traitée et contrôlée est stockée dans un château d’eau puis distribuée. À la maison, en cas de doute sur l’eau, on suit les consignes des autorités sanitaires.

Quiz : teste-toi

1. La grille du dégrillage arrête :
  1. les microbes
  2. les gros débris
  3. le sel
  4. le chlore

Réponse : les gros débris. Feuilles, branches, plastiques…

2. Le filtre à sable retient :
  1. les fines particules
  2. les microbes uniquement
  3. l’eau
  4. le chlore

Réponse : les fines particules. L’eau devient limpide.

3. Le chlore sert à :
  1. colorer l’eau
  2. détruire les microbes
  3. faire tomber la boue
  4. sucrer l’eau

Réponse : détruire les microbes. C’est la désinfection.

4. Une eau potable :
  1. peut être bue sans danger
  2. est toujours de l’eau de pluie
  3. contient des microbes
  4. est forcément gazeuse

Réponse : peut être bue sans danger. Elle ne présente pas de danger pour la santé.

5. La décantation est plus efficace si :
  1. l’eau est agitée
  2. on laisse reposer plus longtemps
  3. on ajoute du sable
  4. on chauffe l’eau

Réponse : on laisse reposer plus longtemps. Les particules ont le temps de tomber.

Oxydation des corps purs simples

Cours de physique-chimie de 3e (les réactions chimiques), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • L’oxydation d’un corps pur simple est sa réaction avec le dioxygène : il se forme un oxyde.
  • Métaux : 3 Fe + 2 O₂ → Fe₃O₄ (oxyde magnétique) ; 2 Cu + O₂ → 2 CuO (noir) ; 4 Al + 3 O₂ → 2 Al₂O₃ (alumine). Leurs oxydes sont solides.
  • Non-métaux : C + O₂ → CO₂ ; S + O₂ → SO₂. Leurs oxydes sont gazeux.
  • Une oxydation est vive si elle s’accompagne de chaleur et de lumière (combustion), lente sinon.
  • La rouille est une oxydation lente du fer qui nécessite du dioxygène et de l’eau. On protège le fer par peinture, graisse ou zinc ; l’alumine protège l’aluminium.

Quiz : teste-toi

1. L’oxydation d’un métal est sa réaction avec :
  1. l’eau
  2. le dioxygène
  3. le diazote
  4. le dihydrogène

Réponse : le dioxygène. Avec le dioxygène.

2. La combustion du fer dans le dioxygène donne :
  1. CuO
  2. Fe₃O₄
  3. CO₂
  4. Al₂O₃

Réponse : Fe₃O₄. L’oxyde magnétique Fe₃O₄.

3. L’oxyde du soufre est :
  1. un solide noir
  2. un gaz à odeur piquante
  3. un liquide
  4. un métal

Réponse : un gaz à odeur piquante. SO₂, gazeux.

4. Un clou rouille dans :
  1. l’air sec
  2. l’eau bouillie sous l’huile
  3. l’air humide
  4. le vide

Réponse : l’air humide. Il faut air + eau.

5. La rouille est une oxydation :
  1. vive
  2. lente
  3. impossible
  4. électrique

Réponse : lente. Lente, sans flamme.

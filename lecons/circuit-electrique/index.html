Le circuit électrique

Cours de physique-chimie de 6e (électricité), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • Un circuit électrique simple est constitué d’un générateur (pile), d’un ou plusieurs récepteurs (lampe, moteur…), d’un interrupteur et de fils de connexion, formant une boucle.
  • Le courant électrique ne circule que si le circuit est fermé. Si le circuit est ouvert (interrupteur ouvert, fil débranché), il ne circule pas.
  • Par convention, à l’extérieur du générateur, le courant circule de la borne + vers la borne −.
  • Les conducteurs laissent passer le courant (métaux, graphite) ; les isolants ne le laissent pas passer (plastique, bois, verre, caoutchouc, papier).
  • On représente un circuit par un schéma normalisé : chaque élément a un symbole.

Quiz : teste-toi

1. Dans un circuit, la pile est :
  1. le récepteur
  2. le générateur
  3. l’interrupteur
  4. un isolant

Réponse : le générateur. Elle fournit le courant.

2. La lampe brille si le circuit est :
  1. ouvert
  2. fermé
  3. coupé
  4. sans pile

Réponse : fermé. Le courant doit faire une boucle.

3. Lequel est un isolant ?
  1. le cuivre
  2. le fer
  3. le plastique
  4. l’aluminium

Réponse : le plastique. Le plastique ne conduit pas le courant.

4. La mine d’un crayon (graphite) est :
  1. isolante
  2. conductrice
  3. un générateur
  4. magnétique

Réponse : conductrice. Le graphite conduit le courant.

5. Le courant sort de la pile par :
  1. la borne −
  2. la borne +
  3. le milieu
  4. les deux bornes

Réponse : la borne +. Sens conventionnel : du + vers le −.

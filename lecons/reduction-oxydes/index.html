Réduction des oxydes

Cours de physique-chimie de 3e (les réactions chimiques), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • Réduire un oxyde, c’est lui enlever son oxygène.
  • Réduction de l’oxyde de cuivre par le carbone : 2 CuO + C → 2 Cu + CO₂ (il se forme du cuivre rouge ; le CO₂ trouble l’eau de chaux).
  • Aluminothermie : Fe₂O₃ + 2 Al → 2 Fe + Al₂O₃ (réaction très vive, utilisée pour souder les rails).
  • Le corps qui capte l’oxygène est le réducteur (il est oxydé) ; l’oxyde qui le cède est l’oxydant (il est réduit).
  • Une réduction s’accompagne toujours d’une oxydation : c’est une oxydoréduction. La métallurgie obtient les métaux par réduction de leurs minerais.

Quiz : teste-toi

1. Réduire un oxyde, c’est :
  1. lui ajouter de l’oxygène
  2. lui enlever son oxygène
  3. le dissoudre
  4. le refroidir

Réponse : lui enlever son oxygène. Lui enlever son oxygène.

2. Lors du chauffage de CuO avec du carbone, le gaz formé :
  1. rallume une bûchette
  2. trouble l’eau de chaux
  3. aboie à la flamme
  4. est du dioxygène

Réponse : trouble l’eau de chaux. C’est du dioxyde de carbone.

3. Dans Fe₂O₃ + 2 Al → 2 Fe + Al₂O₃, le réducteur est :
  1. Fe₂O₃
  2. Al
  3. Fe
  4. Al₂O₃

Réponse : Al. L’aluminium capte l’oxygène.

4. Le réducteur, au cours de la réaction :
  1. est réduit
  2. est oxydé
  3. ne change pas
  4. disparaît sans réagir

Réponse : est oxydé. Il gagne de l’oxygène : il est oxydé.

5. L’aluminothermie sert à :
  1. fabriquer de l’eau
  2. souder des rails
  3. produire du dioxygène
  4. refroidir les métaux

Réponse : souder des rails. Le fer liquide soude les rails.

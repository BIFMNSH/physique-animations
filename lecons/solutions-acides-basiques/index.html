Solutions acides, basiques et neutres

Cours de physique-chimie de 3e (les réactions chimiques), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • Le pH d’une solution aqueuse est un nombre compris entre 0 et 14. On le mesure avec un pH-mètre ou du papier pH.
  • Une solution est acide si pH < 7, neutre si pH = 7, basique si pH > 7.
  • Exemples : jus de citron, vinaigre, jus de bissap (acides) ; eau pure, eau salée (neutres) ; eau savonneuse, eau de Javel, soude (basiques).
  • Les indicateurs colorés changent de couleur selon le pH : le BBT est jaune en milieu acide, vert en milieu neutre, bleu en milieu basique.
  • La dilution rapproche le pH de 7. Acides et bases concentrés sont corrosifs : gants, lunettes, et toujours verser l’acide dans l’eau.

Quiz : teste-toi

1. Une solution de pH 3 est :
  1. acide
  2. neutre
  3. basique
  4. pure

Réponse : acide. pH < 7 : acide.

2. L’eau pure a un pH de :
  1. 0
  2. 7
  3. 14
  4. 10

Réponse : 7. pH = 7 : neutre.

3. Dans l’eau de Javel, le BBT devient :
  1. jaune
  2. vert
  3. bleu
  4. rouge

Réponse : bleu. Milieu basique : bleu.

4. Quand on dilue un acide, son pH :
  1. diminue
  2. augmente vers 7
  3. dépasse 7
  4. reste le même

Réponse : augmente vers 7. Il se rapproche de 7.

5. L’instrument le plus précis pour mesurer le pH est :
  1. le papier pH
  2. le pH-mètre
  3. le BBT
  4. le thermomètre

Réponse : le pH-mètre. Le pH-mètre.

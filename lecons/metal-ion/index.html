Transformation d’un métal en ion et inversement

Cours de physique-chimie de 4e (les ions), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • Le fer réagit avec l’acide chlorhydrique : il se forme du dihydrogène (détonation à la flamme) et des ions fer II. Bilan : Fe + 2 H+ → Fe2+ + H2.
  • Métal → ion : l’atome de fer perd 2 électrons et devient l’ion Fe2+.
  • Le fer réagit avec les ions cuivre II : du cuivre se dépose et la solution se décolore. Bilan : Cu2+ + Fe → Cu + Fe2+.
  • Ion → métal : l’ion Cu2+ gagne 2 électrons et devient l’atome de cuivre.
  • Tests à la soude : Cu2+ → précipité bleu ; Fe2+ → vert ; Fe3+ → rouille ; Zn2+ et Al3+ → blanc.

Quiz : teste-toi

1. Le gaz dégagé par le fer dans l’acide chlorhydrique est :
  1. le dioxygène
  2. le dihydrogène
  3. le dioxyde de carbone
  4. la vapeur d’eau

Réponse : le dihydrogène. Il produit une détonation à la flamme.

2. La soude donne un précipité bleu avec les ions :
  1. fer II
  2. cuivre II
  3. zinc
  4. aluminium

Réponse : cuivre II. Cu²⁺ + 2 HO⁻ → Cu(HO)₂, bleu.

3. Dans Cu²⁺ + Fe → Cu + Fe²⁺, l’ion cuivre II :
  1. perd 2 électrons
  2. gagne 2 électrons
  3. perd 2 protons
  4. reste inchangé

Réponse : gagne 2 électrons. Il devient du cuivre métal.

4. Précipité vert avec la soude :
  1. ions fer II
  2. ions fer III
  3. ions cuivre II
  4. ions zinc

Réponse : ions fer II. Fe(HO)₂ est vert.

5. Un métal qui devient ion :
  1. gagne des électrons
  2. perd des électrons
  3. gagne des protons
  4. perd des neutrons

Réponse : perd des électrons. Il devient un ion positif.

Les défauts de l’œil et leurs corrections

Cours de physique-chimie de 3e (optique), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • L’œil peut être modélisé par une lentille convergente (le cristallin) et un écran (la rétine).
  • Œil normal : l’image d’un objet lointain se forme sur la rétine. Pour voir de près, le cristallin se bombe : c’est l’accommodation.
  • Myopie : l’œil est trop long, l’image d’un objet lointain se forme avant la rétine ; le myope voit mal de loin. Correction : lentille divergente.
  • Hypermétropie : l’œil est trop court, l’image se forme derrière la rétine ; il voit mal de près. Correction : lentille convergente.
  • Presbytie : avec l’âge, le cristallin accommode moins ; on voit mal de près. Correction : lentille convergente (lunettes de lecture).

Quiz : teste-toi

1. Dans l’œil, le rôle de l’écran est joué par :
  1. la cornée
  2. le cristallin
  3. la rétine
  4. la pupille

Réponse : la rétine. La rétine.

2. Un œil myope forme l’image d’un objet lointain :
  1. sur la rétine
  2. avant la rétine
  3. derrière la rétine
  4. nulle part

Réponse : avant la rétine. Avant la rétine.

3. La myopie se corrige avec une lentille :
  1. convergente
  2. divergente
  3. plane
  4. colorée

Réponse : divergente. Divergente.

4. Les lunettes de lecture d’un presbyte sont :
  1. divergentes
  2. convergentes
  3. teintées
  4. sans vergence

Réponse : convergentes. Convergentes.

5. L’accommodation est :
  1. le changement de la pupille
  2. la déformation du cristallin pour voir de près
  3. la fatigue de l’œil
  4. le port de lunettes

Réponse : la déformation du cristallin pour voir de près. Le cristallin se bombe.

Combustion du soufre

Cours de physique-chimie de 5e (mélanges et réactions chimiques), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • Le soufre est un solide jaune. Chauffé, il fond puis s’enflamme et brûle avec une flamme bleue, plus vive dans le dioxygène pur que dans l’air.
  • Au cours de la combustion, le soufre et le dioxygène disparaissent ; il se forme du dioxyde de soufre, un gaz incolore à l’odeur suffocante.
  • Le dioxyde de soufre rougit le papier pH humide (gaz acide) et décolore la solution violette de permanganate de potassium.
  • Bilan : soufre + dioxygène → dioxyde de soufre ; équation : S + O2 → SO2.
  • Le dioxyde de soufre est toxique et polluant : il est à l’origine des pluies acides. On manipule le soufre sous la hotte.

Quiz : teste-toi

1. Le soufre est :
  1. un liquide bleu
  2. un solide jaune
  3. un gaz
  4. un métal gris

Réponse : un solide jaune. Solide jaune.

2. Le gaz formé par la combustion du soufre :
  1. trouble l’eau de chaux uniquement
  2. décolore le permanganate
  3. est sans odeur
  4. est du dioxygène

Réponse : décolore le permanganate. Test du SO₂.

3. Le dioxyde de soufre est :
  1. basique
  2. acide
  3. neutre
  4. sucré

Réponse : acide. Il rougit le papier pH humide.

4. L’équation de la combustion du soufre :
  1. C + O₂ → CO₂
  2. S + O₂ → SO₂
  3. S + H₂ → H₂S
  4. 2S + O₂ → 2SO

Réponse : S + O₂ → SO₂. S + O₂ → SO₂.

5. Le SO₂ rejeté dans l’air provoque :
  1. des arcs-en-ciel
  2. des pluies acides
  3. plus d’ozone
  4. rien du tout

Réponse : des pluies acides. Pluies acides.

Dilatation des gaz

Cours de physique-chimie de 5e (propriétés physiques de la matière), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • Lorsqu’on chauffe un gaz qui peut changer de volume (ballon souple, piston, bulles qui s’échappent), son volume augmente : il se dilate. Lorsqu’on le refroidit, il se contracte.
  • Expériences : un ballon de baudruche sur un ballon de verre gonfle dans l’eau chaude ; l’air chauffé par les mains s’échappe en bulles par un tube plongé dans l’eau.
  • Pour un même échauffement, les gaz se dilatent beaucoup plus que les liquides, qui se dilatent plus que les solides.
  • À l’échelle des particules : chauffées, elles s’agitent plus vite et occupent plus de place.
  • Dans un récipient rigide et fermé (bouteille de gaz, aérosol), le gaz ne peut pas se dilater : c’est sa pression qui augmente quand on chauffe, ce qui peut faire éclater le récipient. On les éloigne donc de la chaleur ; on vérifie la pression des pneus à froid. Application : la montgolfière (air chaud).

Quiz : teste-toi

1. Un gaz refroidi :
  1. se dilate
  2. se contracte
  3. explose
  4. devient plus chaud

Réponse : se contracte. Son volume diminue.

2. Le ballon de baudruche gonfle dans l’eau chaude car :
  1. l’eau entre dedans
  2. l’air se dilate
  3. le verre fond
  4. l’air disparaît

Réponse : l’air se dilate. L’air chauffé se dilate.

3. Pourquoi ne faut-il pas chauffer un aérosol ?
  1. il se vide
  2. le gaz se dilate et peut le faire éclater
  3. il devient froid
  4. il change de couleur

Réponse : le gaz se dilate et peut le faire éclater. Le gaz dilaté peut faire éclater le récipient.

4. Qui se dilate le moins ?
  1. l’air
  2. l’alcool
  3. le fer
  4. l’eau

Réponse : le fer. Les solides se dilatent le moins.

5. Une montgolfière s’élève grâce à :
  1. l’air froid
  2. l’air chaud dilaté
  3. l’eau
  4. le vent seulement

Réponse : l’air chaud dilaté. L’air chaud, dilaté, est plus léger.

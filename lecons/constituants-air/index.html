Les constituants de l’air

Cours de physique-chimie de 6e (les combustions), suivant la progression du programme MENA de Côte d’Ivoire : un résumé vidéo narré d’une minute, une simulation à manipuler, un défi chronométré et un quiz corrigé.

Ouvrir la leçon interactiveAller à la simulation

À retenir

  • L’air est un mélange de gaz.
  • Il contient environ 78 % de diazote (4/5), 21 % de dioxygène (1/5) et 1 % d’autres gaz (argon, dioxyde de carbone, vapeur d’eau…).
  • Le dioxygène entretient les combustions : une bûchette incandescente s’y rallume. Il est aussi indispensable à la respiration.
  • Le diazote n’entretient pas les combustions : une bûchette incandescente s’y éteint.
  • Expérience : la paille de fer humide qui rouille dans une éprouvette retournée sur l’eau consomme le dioxygène ; l’eau monte d’environ 1/5 du volume.

Quiz : teste-toi

1. L’air est :
  1. un corps pur
  2. un mélange de gaz
  3. un liquide
  4. du dioxygène pur

Réponse : un mélange de gaz. Un mélange.

2. Le diazote représente environ :
  1. 1/5 de l’air
  2. 4/5 de l’air
  3. 1/2 de l’air
  4. 1 % de l’air

Réponse : 4/5 de l’air. Environ 78 %.

3. Le gaz qui rallume une bûchette incandescente est :
  1. le diazote
  2. le dioxygène
  3. l’argon
  4. la vapeur d’eau

Réponse : le dioxygène. Le dioxygène.

4. Dans l’expérience de la paille de fer, l’eau monte car :
  1. l’eau s’évapore
  2. le fer consomme le dioxygène
  3. le diazote disparaît
  4. il fait chaud

Réponse : le fer consomme le dioxygène. Le dioxygène est consommé.

5. Sur 100 molécules d’air, combien de dioxygène environ ?
  1. 78
  2. 21
  3. 1
  4. 50

Réponse : 21. Environ 21.
